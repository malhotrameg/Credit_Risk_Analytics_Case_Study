# Credit Risk Prediction and Explainable Credit Scoring System

## Business Problem

Can we identify high-risk borrowers before extending credit?

## Dataset

Give Me Some Credit Dataset

Records: 150,000+

Target:
SeriousDlqin2yrs

## Technology Stack

Python
Pandas
Scikit-Learn
XGBoost
SHAP
Matplotlib
Seaborn

## Workflow

1. Data Understanding
2. EDA
3. Data Cleaning
4. Feature Engineering
5. Logistic Regression
6. Random Forest
7. XGBoost
8. SHAP Explainability

## Results

| Model | ROC-AUC |
|---------|---------|
| Logistic Regression | 0.716 |
| Random Forest | 0.850 |
| XGBoost | 0.869 |

## Key Findings

- Historical delinquency is strongest predictor.
- Credit utilization impacts risk.
- XGBoost performed best.
